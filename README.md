# 主义星图 · Ism Atlas

把 42 种活法放进一个可以旋转、缩放、点开的 3D 空间：既有躺平、内卷、社恐这些嘴边的说法，也保留了虚无、斯多葛、存在主义这些被讨论了几千年的主张。

没有标准答案，坐标只是编辑部的主观判断。

## 一键部署

### Windows

1. 把仓库下载到本地（网页 `Code → Download ZIP`，或 `git clone`）
2. 双击 **`deploy.bat`**
3. 浏览器会自动打开 `http://127.0.0.1:8787/`；关掉那个黑色命令行窗口就停止服务

需要 Python 3 或 Node.js 之一。两个都没有也能用——脚本会退回去直接打开 `index.html`，功能完全一样。

### macOS / Linux

```bash
chmod +x deploy.sh
./deploy.sh
```

### 不想部署

直接双击 `index.html` 也能用。three.js 已放在 `vendor/` 里，离线可用，不需要装任何东西。

## 怎么玩

- **拖拽**旋转，**滚轮**缩放，**点击圆点**看详情
- **右下角切换两套世界**：
  - **生活模式**（30 条）：躺平、内卷、社恐、断亲…… 参考系是生活观 / 价值观 / 情感观 / 状态观
  - **哲学模式**（20 条）：虚无、斯多葛、存在主义、观念论…… 参考系是认识论 / 存在论 / 伦理观 / 实践观
- **顶部参考系**：换一套，同一批点的位置就变
- **中心的白点**是原点，点一下回到全景
- **显示名称**：把所有标签打开（默认关，点太密会糊）
- **自由漫游**：点画面锁定鼠标，移动转头、滚轮前后，`Esc` 退出（手机上没有）
- **＋ 添加**：自己加一个，八条轴打分，存在浏览器本地

## 目录

```
deploy.bat          Windows 一键启动
deploy.sh           macOS / Linux 一键启动
push.bat            改完代码一键提交推送
index.html          页面结构
app.js              3D 场景、交互、详情渲染
data/isms.json      42 条主义（含八维打分）
data/sources.json   来源说明
data/editorial.json 编者的话、轴说明
data/isms.js        上面三个打包后的内联数据（页面实际读这个）
tools/serve.js      没有 Python 时的兜底静态服务器
tools/data_all.py   生成数据
tools/build_data.py 打包数据
vendor/three.min.js three.js r160
```

改完 `data/*.json` 后跑一次：

```bash
python tools/build_data.py
```

## 三条轴的说明

八条轴：消极↔积极、放松↔用力、向内↔向外、现实↔玄学、独处↔群居、省↔花、当下↔长期、顺从↔反抗。

每套参考系取其中三条。轴的两端不是「好」与「坏」，只是方向。
